# KPM CSV metadata patch snapshots

Original and patched FlexRIC source files, unified diff and SHA-256 checksums for the three metadata patches.

Apply patches in the order recorded in manifest.json. Earlier interoperability patches remain documented separately and are applied by Dockerfile.flexric-kpm-csv-metadata.

Replay is a source transformation check. Runtime validation uses validate-kpm-csv-metadata.py and validate-kpm-csv-ue-identity.py.
